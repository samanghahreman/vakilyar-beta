## درباره‌ی برنامه

محاسبه‌ی مهریه، تقسیم ارث و دیه رایگان است؛ خسارت تأخیر تأدیه، نفقه، مالیات بر ارث، هزینه‌ی دادرسی، مهلت‌های قانونی و پرونده و یادآوری با اشتراک باز می‌شوند. کنار هر رقم مستند ماده‌ی قانونی و خروجی PDF فارسی می‌آید.

برنامه **هیچ مجوز اینترنتی ندارد**؛ همه‌ی محاسبات و داده‌ها روی خود دستگاه می‌مانند.

این مخزن فقط صفحه‌ی انتقال (GitHub Pages) دوره‌ی آزمایشی است و کد منبع برنامه در آن نیست.

# وکیل‌یار — نسخه آزمایشی

ماشین‌حساب حقوقی اندروید، ساخته‌شده در تیم قطره.

این مخزن **فقط برای توزیع نسخه آزمایشی** است و کد منبع در آن نیست.

## دریافت

صفحه دانلود: **https://samanghahreman.github.io/vakilyar-beta/**

برای دانلود به کد دعوت نیاز دارید. اگر تستر هستید و کدی ندارید، از تیم بخواهید.

## درباره برنامه

هشت ماشین‌حساب حقوقی (مهریه، تأخیر تأدیه، ارث، دیه، نفقه، مالیات بر ارث،
هزینه دادرسی و مهلت‌های قانونی)، به‌همراه پرونده‌های شخصی و یادآور جلسات با
آلارمی که حتی وقتی برنامه بسته است زنگ می‌زند.

برنامه **هیچ مجوز اینترنتی ندارد**؛ همه محاسبات و داده‌ها روی خود دستگاه
می‌مانند و هیچ‌جا ارسال نمی‌شوند.

> ⚠️ خروجی وکیل‌یار سند غیررسمی است و جایگزین نظر وکیل دادگستری نیست.
